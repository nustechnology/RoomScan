## Code Review

For code reviews, read and follow:

`.agents/skills/code-review-and-quality/SKILL.md`

Treat that skill as the source of truth for:

- Review methodology
- Finding severity and prefixes
- Review structure
- Approval criteria

Project-specific review requirements may supplement the skill, but must not
redefine or conflict with its severity conventions.

When reviewing:

- Read the task and expected behavior first.
- Read relevant project documentation.
- Inspect the complete Git change set, including untracked files.
- Inspect related tests and surrounding implementation.
- Run relevant tests and static analysis when practical.
- Include file paths and line numbers for findings.
- Do not modify code unless explicitly requested.
