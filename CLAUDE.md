## Project

RoomScan is a native iOS application built with SwiftUI.

The app allows users to scan indoor spaces using Apple's RoomPlan framework, annotate rooms, and share projects.

---

## Documentation

Before making changes, review the relevant documentation in the `docs/` directory.

Always follow:

- docs/architecture.md
- docs/coding-guidelines.md

Treat these documents as the source of truth for architecture, coding conventions, and design system usage.

## Working Principles

- Reuse existing code and components whenever possible.
- Keep changes small, focused, and consistent with the existing codebase.
- Do not introduce new architectural patterns without a clear reason.
- Ensure the project builds successfully after making changes.
