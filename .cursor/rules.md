# AI Rules

Before making changes:

- Read the relevant documentation under `docs/`.
- Follow the architecture and coding guidelines.
- Do not introduce new architectural patterns without approval.

Implementation:

- Prefer the simplest solution.
- Keep changes small and focused.
- Preserve existing conventions.
- Do not over-engineer.
- Explain architectural changes before implementing them.

Testing:

- Add or update unit tests when business logic changes.
- Run relevant tests after implementation.

Documentation:

- Keep documentation synchronized with code changes.
- Update docs when architecture or behavior changes.
